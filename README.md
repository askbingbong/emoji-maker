# Emoji Maker

A mobile-friendly, fully in-browser maker for animated Discord emojis, including sets of emojis that animate together.
No build step: open `index.html` or host the folder (e.g. GitHub Pages). Images never leave your device.

- Motions: jump, spin, flip, shake, pulse, heartbeat, wobble, swing, float, zoom, jelly, ta-da, orbit, blink, waddle, drop
- Travel across 1–12 emojis: bounce, slide, wavy path, rain, bubbles, fountain (count, spawn rate, speed, size, spin, seed…)
- Multiple images, background removal, outline/glow/shadow, rainbow colour cycling
- Exports GIFs auto-shrunk to Discord's 256 KB limit, as individual files or a ZIP (`name_1`, `name_2`, …)
